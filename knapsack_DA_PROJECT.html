Theory

The knapsack problem

There are n items. Item i has a weight wi and a profit pi. A knapsack holds at most weight W. Choose items so that the total profit is as large as possible and the total weight stays within W.

Fractional knapsack (Greedy method)

Items can be broken into parts, so a fraction of an item gives the same fraction of its profit. The greedy choice is to take items with the best profit per unit weight first.

  1. Compute the ratio pi / wi for every item.
  2. Sort the items by ratio, highest first.
  3. Take whole items while they fit.
  4. For the first item that does not fit, take the fraction (remaining capacity) / wi and stop.

Time: O(n log n) because of sorting. Space: O(n). Optimal: yes, for the fractional problem.

0/1 knapsack (Dynamic Programming)

Each item is taken completely or not at all. Greedy can fail here, so we use a table. Let K[i][c] be the best profit using the first i items with capacity c.

K[0][c] = 0,  K[i][0] = 0
if w_i > c :  K[i][c] = K[i-1][c]
else        :  K[i][c] = max( K[i-1][c],  p_i + K[i-1][c - w_i] )

The answer is K[n][W]. To find which items were chosen, start at K[n][W] and move up: if K[i][c] ≠ K[i-1][c], item i was taken, so subtract its weight from c.

Time: O(n × W). Space: O(n × W) (O(W) if you only need the profit). It is called pseudo-polynomial because it depends on the value of W, not just on n.

The fractional profit is always greater than or equal to the 0/1 profit, because splitting items gives more freedom. In the classic example (weights 10, 20, 30, profits 60, 100, 120, capacity 50) fractional gives 240 and 0/1 gives 220.
