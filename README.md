# KnapsackLab – DAA Project 🎒

KnapsackLab is a Python-based interactive web application that demonstrates and compares two classic Knapsack algorithms: **Fractional Knapsack** and **0/1 Knapsack**.

The application allows users to add items with their weight and profit, set a knapsack capacity, and calculate the maximum achievable profit using both approaches.

## Features
- Add and remove items dynamically.
- Set custom knapsack capacity.
- **Fractional Knapsack:** Greedy approach based on profit-to-weight ratio.
- **0/1 Knapsack:** Dynamic Programming approach using a DP table.
- Compare maximum profit and selected items.
- Visual representation of item selection and capacity usage.
- Displays the DP table for smaller inputs.
